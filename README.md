# 🚘 Adyant Automotives CRM

Hi, I’m **Pratik Dayma**, and this is my project **Adyant Automotives CRM**, a full-stack web application I developed using the **MERN stack (MongoDB, Express.js, React.js, Node.js)**.  

This project is a fictional automotive company CRM where I showcase how real-world businesses can handle customer inquiries, admin authentication, and inquiry management through a clean and scalable web app.

---

## 🌟 Project Overview
I built this project with the goal of learning and demonstrating how a real **Customer Relationship Management (CRM) system** works in practice.  

- On the **frontend**, I created a responsive UI where visitors can submit inquiries using a **Contact Us form**.  
- On the **backend**, I implemented **secure admin authentication** and built an **admin dashboard** where administrators can:  
  - Log in securely using JWT-protected routes.  
  - View and manage inquiries in real-time.  
  - Respond to customers efficiently.  

This project demonstrates my understanding of:
- RESTful API design  
- Protected routes & JWT authentication  
- State management and real-world workflows  

---

## 🌟 Features I Implemented
- 🏎️ **Customer Inquiry System** – Visitors can easily submit their queries.  
- 🔐 **Secure Authentication** – Admin login system using JWT & bcrypt.js.  
- 📊 **Admin Dashboard** – A centralized place to view, manage, and respond to inquiries.  
- 📱 **Responsive Design** – Built with React and Tailwind for smooth mobile and desktop experience.  
- ⚡ **Clean API Architecture** – Built with Express.js and REST principles.  

---

## 🏗️ Tech Stack I Used
### Frontend
- ⚛️ React.js (with Hooks & Context/Redux for state management)  
- 🎨 Tailwind CSS / Bootstrap for styling  
- 🔄 Axios for API calls  

### Backend
- 🟢 Node.js + Express.js  
- 🔐 JWT & bcrypt.js for secure authentication  
- 📂 Multer (planned for file uploads/attachments if needed)  

### Database
- 🍃 MongoDB with Mongoose  

### Other Tools
- 🛠️ Git & GitHub for version control  
- ☁️ Deployment on Render / Vercel / Netlify
